# 오목눈이 피하기

GitHub Pages에서 바로 실행할 수 있는 간단한 피하기 게임입니다.

## 실행 방법

1. 이 폴더 안의 파일을 GitHub 저장소에 올립니다.
2. GitHub 저장소의 **Settings → Pages**로 갑니다.
3. 배포 소스를 `Deploy from a branch`로 선택합니다.
4. `main` 브랜치의 `/ (root)`를 선택하고 저장합니다.
5. 잠시 기다리면 GitHub Pages 주소에서 게임이 실행됩니다.

## 조작

- PC: ← → 또는 A / D
- 모바일: 아래의 좌우 버튼
- 게임 화면을 손가락으로 좌우 드래그해도 이동합니다.

## 이미지 교체

`images/character.png`를 같은 파일명으로 다른 PNG로 바꾸면 캐릭터가 교체됩니다.
